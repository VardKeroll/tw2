# tw2

Как добавить свои файлы (How to add your own files):

## Русский
1. Создайте файл в вашей локальной копии репозитория
2. Добавьте файл в git: `git add имя_файла`
3. Сделайте коммит: `git commit -m "Добавить мой файл"`
4. Отправьте изменения: `git push`

## English
1. Create a file in your local repository copy
2. Add the file to git: `git add filename`
3. Commit the file: `git commit -m "Add my file"`
4. Push the changes: `git push`

## Пример (Example)
См. файл `example.txt` для примера добавления файла.
See `example.txt` file for an example of adding a file.
